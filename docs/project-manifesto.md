# THIS IS A LEARNING PROJECT

Stone Shelter Assistant is a hands-on lab in which a Java developer learns Python and modern AI engineering by building a fictional pet-rock shelter. The first goal is a working search assistant, not a production shelter system. PostgreSQL holds stone records, Typesense supports lexical search, and Qdrant holds vectors for semantic search. LangChain and LangGraph will connect retrieval tools and let an LLM choose a bounded path through them. The assistant should combine operational records with a stone encyclopedia and a fictional type-compatibility guide, then ground its answers in retrieved evidence. We first build a simple happy-path pilot and inspect its behavior. After that, we measure retrieval and answer quality, trace decisions, and improve one factor at a time. Code should remain clear, typed, and idiomatic even while production recovery and broad edge-case handling are deferred.
